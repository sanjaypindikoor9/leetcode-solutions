# Git Commands

```bash
git init
git branch -M main
git remote add origin <YOUR-GITHUB-REPOSITORY-URL>
git add .
git commit -m "Add Activity 6 LeetCode solutions with tests and docs"
git push -u origin main
```

After pushing, verify the README, folders, code files, documentation, and progress tracker on GitHub.

For the Activity 6 rubric, add the actual LeetCode Accepted screenshots after you submit each solution.
