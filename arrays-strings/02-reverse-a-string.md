# Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

## Approach

Use two pointers, one at the beginning and one at the end of the character array. Swap the characters and move both pointers toward the center.

## Complexity

- Time: O(n)
- Space: O(1)

## Notes

The solution modifies the input array in place, so no additional string or array is required.
